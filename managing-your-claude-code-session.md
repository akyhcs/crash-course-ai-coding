Here’s a **copy‑friendly summary** of the key commands and concepts for managing your Claude Code session:

---

### 📝 Essential Commands
- **Open and chat** → Just type messages like any chat app.  
- **Multi‑line input** → Run `/terminal-setup` to enable **Shift+Enter** for new lines.  
- **Check usage** → `/usage` shows session allowance, weekly limit, and tokens used.  
- **Inspect context** → `/context` visualizes system prompt, skills, messages, and total token capacity.  
- **Reset context** → `/clear` wipes conversation history for a fresh start.  
- **Interrupt agent** → Press **Escape** to stop mid‑run. Type *carry on* to resume.

---

### ⚙️ Key Concepts
- **Context window** → Holds system prompt, skills, and conversation history.  
- **Stateless model** → Clearing context erases memory of prior conversation.  
- **Multi‑line prompts** → Crucial for complex instructions.  
- **Usage limits** → Once reached, you must wait for reset.  
- **Interrupt/resume** → Escape halts execution; *carry on* continues.

---

### ✅ Quick Reference
- `/terminal-setup` → Enable Shift+Enter for multi‑line input  
- `/usage` → Check remaining allowance  
- `/context` → See what fills your context window  
- `/clear` → Start fresh  
- **Escape** → Interrupt agent  
- *carry on* → Resume after interruption
